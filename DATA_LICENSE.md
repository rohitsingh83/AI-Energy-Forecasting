UCI Machine Learning Repository, donated 2012. DOI: [10.24432/C58K54](https://doi.org/10.24432/C58K54).

`data/raw/uci_household_hourly.csv` is an **adaptation**, not the unmodified source.
This project averages minute-averaged `Global_active_power` (kW) into hourly power.
Hours with fewer than 54 valid minutes are set to missing. `Observed_minutes` and
`Source_minutes` preserve coverage evidence. The cleaning pipeline trims unobserved
edges, fills at most three hours using past values, and excludes imputed target
hours from training labels and evaluation. Source and transformed-file SHA256
hashes are in `data/raw/uci_household_hourly.metadata.json`.

this attribution and describe any additional changes if you redistribute them.
The original 126.8 MB text and ~20 MB ZIP are not distributed in this project.

## Synthetic dataset

`data/raw/energy_data.csv` is generated by `generate_data.py` with seed 42.
It represents a fictitious mixed-use building, not a real customer, company,
city or meter. This project makes its synthetic data available under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/
The generator's source code is covered by the project's MIT software license.
