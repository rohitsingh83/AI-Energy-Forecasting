System Architecture & Engineering Pipeline

End-to-end design from raw meter ingestion to decision optimization.

End-to-End Forecasting Pipeline

[RAW TELEMETRY] ├── Synthetic Building (17,520 hours) └── UCI Household #235 (2,075,259 raw minutes aggregated to 34,587 clean hours) │ ▼ [CAUSAL PREPROCESSING] ├── Data validation & missingness masks ├── Forward/causal gap filling for uninterrupted lag generation └── Strict masking: Imputed rows are never included in test scores │ ▼ [15 DOMAIN-DRIVEN FEATURES (PAST-ONLY)] ├── Autoregressive Lags: lag_1, lag_2, lag_3, lag_24, lag_48, lag_168 ├── Rolling Statistics: rolling_mean_24h, rolling_std_24h, rolling_mean_168h (all shifted by 1) └── Cyclic Calendar: sin/cos encodings for hour_of_day, day_of_week, month_of_year │ ▼ [CHRONOLOGICAL SPLIT (70% / 15% / 15%)] ├── Train Split: Fit estimators on historical data ├── Validation Split: Model champion selection based strictly on 24h RMSE └── Test Split: One-time honest holdout reporting (No leakage) │ ▼ [RECURSIVE MULTI-STEP ENGINE & DECISION SANDBOX] ├── Step-by-step recursive rollouts for 24h, 48h, 168h horizons ├── Empirical 90th percentile uncertainty band estimation └── Time-of-Use load shifting optimization (conserved total energy)
HONEST DISCLOSURE 01
Energy-Conserving Physics
Load shifting moves energy; it does not eliminate it. Under standard constant grid carbon factor assumptions, modeled emissions reduction is exactly 0 kg. We do not invent unrealistic ESG metrics.
HONEST DISCLOSURE 02
Validation Champion Selection
The winning model is selected purely based on Validation 24-hour RMSE. The Test split is never used to select models or tune hyperparameters, avoiding data snooping bias.
HONEST DISCLOSURE 03
Separate Tasks
Synthetic building forecasting (large commercial profile, R² 0.83) and UCI household forecasting (single volatile family residence, R² 0.57) are distinct tasks with different signal-to-noise ratios.
