## Deliberate corrections, not missing features

- Chronological splits replace the brief's random split.
- Past demand features augment calendar-only inputs.
- MLP scaling and honest convergence reporting replace unscaled opaque fitting.
- A horizon/history-based API replaces insufficient arbitrary hour/day payloads.
- Explicit kW/kWh and coverage checks prevent unit/aggregation mistakes.
- Historical replay replaces misleading claims of live corporate monitoring.
- Measured public and synthetic sources remain distinct.
- Forecast error improvement is not called electricity saving.
- Cost scenarios are hypothetical; conserved-energy constant-intensity carbon benefit is zero.
- Unsupported market, grid-loss, salary, current-hiring and funding statistics are not repeated.
